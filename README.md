# Shanvi Tours & Travels — Next.js site

The 2026 rebuild of shanvitoursandtravels.com: Next.js 16 (App Router, static), Tailwind CSS v4,
Motion for animation, Lenis for smooth scrolling, Lucide icons. The legacy PHP site in the repo root
is untouched; this folder replaces it once deployed.

## Run it

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Deploy (Vercel)

In the Vercel project settings set **Root Directory = `web`** (framework preset: Next.js).
The root `vercel.json` belongs to the PHP site and is ignored once the root directory is `web`.

## What's where

- `lib/content.ts` — fleet, tariffs, seat layouts, destinations, services, areas (edit prices here).
- `lib/generated.ts` — SEO copy ported from the PHP site (page meta, FAQs, reviews, blog articles).
  Regenerated by the extraction script used during the rebuild; safe to edit by hand.
- `lib/schema-data.ts` — site-wide JSON-LD (Organization / TravelAgency, WebSite).
- `components/` — `motion.tsx` (smooth scroll, cursor, reveals, marquee, tilt…),
  `home-hero.tsx`, `booking.tsx`, `fleet-explorer.tsx` (seat map), `route-map.tsx`,
  `fare-calculator.tsx`, `destinations-scroller.tsx`, `sections.tsx`, `chrome.tsx` (nav/footer).
- `app/sitemap.ts` — generated sitemap with image entries; `public/robots.txt` points to it.

## SEO continuity

- Same page slugs as before; old `*.php` URLs permanently redirect (see `next.config.ts`).
- Titles, descriptions, keywords, FAQ copy and JSON-LD carried over; canonicals are now clean URLs.
- Forms send enquiries to WhatsApp (no server mail), as on the PHP site.
